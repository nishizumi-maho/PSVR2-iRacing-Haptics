# Changelog

## 0.1.0 — 2026-07-29

- primeira versão independente para Windows x64 e .NET 8;
- carregamento dinâmico da C API do PSVR2 Toolkit;
- teste manual e dispositivo de rumble simulado;
- leitura direta da memória compartilhada do iRacing;
- detectores de colisão, zebra forte, queda de roda, pouso, compressão e
  capotamento;
- filtros, jerk, histerese, cooldown e proteção contra frenagem/bloqueio;
- fila de rumble com prioridades, cancelamento, limites e `0 Hz` obrigatório;
- interface em português do Brasil;
- perfis Padrão, Suave, Forte e Personalizado;
- logs rotativos, gravação JSONL, replay e análise de marcações;
- onze cenários de telemetria;
- 25 testes automatizados;
- build e pacote portátil autocontido.

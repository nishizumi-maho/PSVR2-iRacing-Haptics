# Security and safety reports

Do not publish a proof of concept that can leave the headset rumble motor active
or expose a credential/user recording.

For a private security report, use GitHub's private vulnerability reporting for
this repository when available. Include the affected version, operating system,
Toolkit version, reproduction steps, whether physical hardware was involved and
the final `Rumble: OFF` log evidence.

For a non-sensitive safety bug, open a GitHub issue and clearly label it as a
safety issue. Stop hardware testing if rumble does not end as expected.

This project does not perform or distribute a PSVR2 jailbreak. Questions and
risks specific to the Toolkit or its jailbreak belong to the upstream PSVR2
Toolkit project.
